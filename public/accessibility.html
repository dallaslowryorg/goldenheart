Accessibility Statement

Golden Heart wants this website to be usable by as many people as possible.

The site is designed with keyboard-accessible navigation, visible focus states, responsive layouts, text alternatives for meaningful images, semantic page structure, and reduced-motion support where possible.

If you encounter an accessibility barrier while using the site, please contact Golden Heart at gldnheartservicedogs@gmail.com or 918-402-2071 and describe the page or feature that is causing difficulty so the issue can be reviewed.
